# BlueBridge for macOS

SwiftUI application shell for macOS 14 and newer. It includes the main window, menu bar presence, route state, devices, mixer, and built-in presets.

Native integration targets:

- CoreAudio output and mixing
- ScreenCaptureKit system/application audio capture
- local discovery and encrypted media transport adapter
- BlueBridge Bluetooth fallback adapter
- Keychain-backed trusted-device identity
