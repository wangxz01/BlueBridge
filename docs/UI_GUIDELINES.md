# BlueBridge 界面规范

## 目标

界面只服务于四类信息：音频来源、目标设备、输出设备、当前状态。装饰元素不得与这些信息竞争。

## 颜色

- 页面背景：`#F4F4F2`
- 卡片：`#FFFFFF`
- 主文字与主要操作：`#171717`
- 次级文字：`#6B6B67`
- 分隔线：`#DDDDD8`
- 在线/正常：`#2E7D4F`，仅用于状态
- 警告：`#A46313`，仅用于需要用户处理的事项

不使用渐变、大面积品牌色、彩色功能卡片或发光效果。

## 信息层级

1. 页面标题和一句当前状态。
2. 当前路由：来源 → 目标 → 输出。
3. 启停主操作。
4. 可选设备和必要参数。
5. 尚未实现或需要权限的说明。

## 文案

- 所有面向用户的界面文案使用简体中文。
- 使用“设备、来源、输出、路由、场景”，不使用 Server / Client。
- 未实现的能力直接标为“暂不可用”，不展示模拟连接或占位数据。
